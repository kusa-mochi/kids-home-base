# kids-home-base
対象年齢：小学校低学年～　自分で自分の日々のスケジュールを管理するための補助ツール。

## 想定する利用シーン（子ども編）

### どこで

自宅で

### 誰が

子どもが

### いつ

毎日、自宅にいる間

### どのようにして

タブレットの画面を見て／操作して

### 何をどうする

- 自分が今何をする時間なのかを都度確認する。
- 何時から何の予定があるのかを把握する。
- 自分で今日・明日の予定を組み立てる。
- 自分で定期的な予定を組み立てる。

## 想定する利用シーン（親編）

### どこで

自宅で

### 誰が

親が

### いつ

必要に応じて

### どのようにして

自身のスマホから

### 何をどうする

- 子どもの予定を確認する。
- 子どもと一緒に今日・明日の予定を組み立てる。
- 子どもと一緒に定期的な予定を組み立てる。

## プログラム実行方法（開発用）

```sh
cd .\docker_kids-home-base
docker compose -f .\compose.dev.yml --env-file .env.local up
```
